      Both lanes are stock products over the same Lakehouse. On the left, Microsoft Data API Builder publishes three curated views as MCP tools; the model reads the question and writes the answer but never writes the query — it picks a tool and fills in arguments, and DAB turns those arguments into SQL. Base tables are not published, so they cannot be reached, and the tools are read-only: there is no write surface to disable. DAB does not return its generated SQL, so the last trace step reads the statement back out of Fabric's own query history — what actually ran, not what we claim ran.
